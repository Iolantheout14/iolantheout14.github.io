🛠️ frpsctl - Simple Control for Your FRP Server

Your friendly command-line assistant for the FRP server — no programming needed!

What does frpsctl do for you? It wraps the FRP server (frps) into a neat, easy-to-use command-line tool. You can generate configuration files, keep the server running like a background service, see an overview of everything at once, and even change settings without fear — it restarts automatically, and if something goes wrong, it rolls back to a safe state.

🧐 What is the FRP Server (frps)?

The FRP server is a powerful tool that helps you expose your home computer or local server to the internet through a technique called NAT traversal. Think of it as a secure bridge — it lets you access your devices from anywhere, even if they're behind a firewall or router. frpsctl makes managing that bridge super easy.

🎯 Why Use frpsctl?

  • 🔥 No complicated manual setup — frpsctl handles all the hard parts.
  • ✍️ Edit simple config files — you don't need to be a programmer to change settings.
  • 🔄 Auto-restart — change your configuration, and frpsctl restarts the server automatically.
  • 🔙 Safety first — if the new configuration has an error, frpsctl rolls back to the previous working one, so your server keeps running.
  • 📊 See everything from one screen — get a combined status of all your tunnels.
  • 🎛️ Runs in the background — start it as a daemon (background service) and forget about it.

✅ What You Need Before You Start

frpsctl is designed for Linux systems only, and it requires frps version 0.70.0 or newer. Don't worry if you're not sure how to check — frpsctl will tell you if something's off.

🧑‍💻 How to Use frpsctl – A Quick Tour

📝 Create a Configuration

Start by telling frpsctl what you want. To create a new configuration, run:

frpsctl init

This creates a simple, clean configuration file (in TOML format) that you can open and edit with any text editor. It looks like plain English, so you'll understand it.

▶️ Start the Server as a Background Service

To keep the FRP server running in the background, just run:

frpsctl start

Frpsctl will run the server as a daemon, so it keeps working even after you close the terminal. Perfect for keeping your tunnels alive.

📊 Check the Overall Status

Want to see if everything is working? Run:

frpsctl status

This gives you an aggregated overview — all your tunnels, connections, and server health on one screen, nicely formatted for humans.

✏️ Change a Setting, Watch the Magic

Open your configuration file, change a port number or add a new tunnel, and save it. Then run:

frpsctl reload

Frpsctl will restart the server with your new settings automatically. And here's the best part: if the new settings have a problem, it automatically rolls back to the previous working configuration, so you're never left with a broken server.

🛑 Stop the Server

When you want to stop everything:

frpsctl stop

It gracefully shuts down the FRP server and cleans up.

💡 Pro tip: you can also mix commands together. For example, frpsctl restart stops and starts the server in one go. And frpsctl view shows your current configuration in the terminal.
